# KiberPride Bot

Discord-бот игрового сервера KiberPride: валюта KP Coin, магазин, наборы на матчи с
автоматическими командами, награды и MVP.

Проект ведёт помощник ZCode, владелец отвечает только за продукт. Начало —
[docs/for-owner/первый-запуск.md](docs/for-owner/первый-запуск.md).

Для агента: отправная точка — [AGENTS.md](AGENTS.md), маршруты — [FLOW.md](FLOW.md), продукт —
[product/spec.md](product/spec.md).
